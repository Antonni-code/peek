# Peek privacy policy

Effective date: 2026-09-22

Peek previews links and organizes selected previews inside the user's browser.

## Data processed locally

Peek stores settings, cached preview metadata, pinned previews, optional Pro preview history, and signed license status in browser-managed local extension storage. This data is used only to provide Peek's features on that device.

## Network requests

When a user requests a preview, Peek contacts the destination URL to retrieve bounded page metadata and readable text. The request omits browser credentials and referrer information. Destination websites may still receive normal network information such as the user's IP address.

For Pro activation and periodic validation, Peek sends the submitted license key and a device/instance identifier to the configured Peek license service, which forwards the request to Creem. The license service does not receive browsing previews, pinned links, or preview history.

## Collection and sharing

Peek includes no analytics, advertising, tracking, or user-account system. Browsing previews, pins, and history are not sold or transmitted to the developer. License information is shared only with Creem as needed to provide and protect the purchased license.

## Retention and control

Users can remove pins, clear local history, export/import Pro data, deactivate a license, or uninstall Peek. Uninstalling removes data controlled by browser extension storage. Creem may retain purchase and licensing records under its own policies and legal obligations.

## Security

Peek uses Manifest V3, a restrictive content security policy, bounded remote fetching, text-only remote rendering, and signed license receipts. No system can guarantee absolute security.

## Changes and contact

Material policy changes will be reflected in a new extension version and updated effective date. Add the final support email or website before Chrome Web Store submission.
