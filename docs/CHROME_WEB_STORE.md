# Chrome Web Store copy

## Name

Peek — Preview links before opening

## Short description

Preview links beside the page. Stay focused, pin what matters, and open only what is worth it.

## Detailed description

Peek shows what is behind a link without pulling you into another tab.

Hold Option on Mac or Alt on Windows/Linux and hover a link. Peek opens a clean preview beside it with the page title, source, summary, image, and quick actions. When a website cannot be previewed safely, Peek gives you an honest fallback instead of a broken frame.

Free includes unlimited previews, quick actions, automatic light/dark appearance, and one pinned preview.

Peek Pro is a $5.99 lifetime purchase with unlimited Peek Stack, searchable local history, reader mode, customization, and local JSON backup. No account. No subscription.

Privacy first:

- previews, pins, history, and settings stay on your device;
- no analytics, ads, or browsing-history collection;
- the small online service is used only to activate and validate Pro licenses;
- remote scripts never run inside previews.

## Permission justifications

### Storage

Stores local settings, cache, pins, optional Pro history, and signed license status.

### Read and change data on websites

Peek must detect the link under the pointer and place the preview beside it. The extension does not edit page content beyond adding its isolated preview surface.

### Host access

The background service worker retrieves the destination page's public metadata for the preview. Requests are bounded and omit credentials. The same HTTPS host access also permits Pro activation and validation against the configured license Worker.
